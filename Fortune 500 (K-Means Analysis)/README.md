
# Fortune 500 Company Segmentation using K-Means Clustering

![Project Overview](../Images/500globalrank.webp)

**This machine learning project analyzes Fortune 500 company data to identify hidden business segments using K-Means clustering and enterprise analytics.**

---

# Executive Summary

- **Project Scope:** Built an unsupervised machine learning model to segment Fortune 500 companies into meaningful business groups.
- **Modeling:** Used K-Means clustering with feature scaling and PCA visualization.
- **Outcomes:** Identified distinct enterprise operating models based on revenue, workforce size, and operational efficiency.

---

# Tech Stack

- **Language Used:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- **Machine Learning:** K-Means Clustering, PCA
- **Development Environment:** Jupyter Notebook
- **Version Control:** Git & GitHub

---

# Key Insights

The clustering analysis identified four major enterprise segments:

- Traditional large enterprises
- High-performance enterprise leaders
- Workforce-driven mega corporations
- Ultra-efficient technology-driven companies

The analysis revealed that Fortune 500 companies operate under significantly different business scaling models.

---

# Cluster Findings

- Some enterprises relied heavily on massive workforce expansion.
- Others generated extremely high revenue with smaller employee counts.
- Revenue efficiency varied dramatically across industries.
- Technology-driven firms demonstrated exceptional operational scalability.
