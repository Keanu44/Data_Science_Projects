# Loan Default Prediction using Support Vector Machine (SVM)

![Project Overview](../Images/loans.png)

**This machine learning project analyzes borrower financial behavior using real-world lending data to predict loan default risk using Support Vector Machine (SVM) classification.**

---

# Executive Summary

- **Project Scope:** Built a classification model to predict whether borrowers are likely to fully repay loans.
- **Modeling:** Used Support Vector Machine (SVM) with feature scaling and categorical encoding.
- **Outcomes:** Identified key borrower patterns associated with default risk including FICO score, interest rates, and loan purpose.

---

# Tech Stack

- **Language Used:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- **Machine Learning:** Support Vector Machine (SVM)
- **Development Environment:** Jupyter Notebook
- **Version Control:** Git & GitHub

---

# Analysis Overview

## Data Preparation
- Cleaned borrower financial records
- Encoded categorical variables
- Scaled numerical features using StandardScaler

## Exploratory Data Analysis
- Loan repayment distribution
- FICO score analysis
- Interest rate comparison
- Loan purpose segmentation

## Machine Learning Workflow
- Train-test split
- Feature scaling
- SVM model training
- Classification evaluation

---

# Key Insights

- Borrowers with lower FICO scores showed higher default risk.
- Higher interest rates were strongly associated with loan repayment failure.
- Debt consolidation and small business loans demonstrated elevated risk profiles.
- Machine learning effectively identified borrower risk patterns.
