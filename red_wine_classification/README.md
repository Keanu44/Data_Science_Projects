# 🍷 Red Wine Quality Classification (Machine Learning Project)

![Project!_overview]()

## 📌 Overview

This project focuses on predicting the quality of red wine based on physicochemical properties using machine learning classification techniques. The goal is to identify patterns between chemical features and wine quality ratings.

---

## 🚀 Project Workflow

### 1. Data Loading

* Dataset: Red Wine Quality dataset
* Features include:

  * Fixed acidity
  * Volatile acidity
  * Citric acid
  * Residual sugar
  * Alcohol content
  * pH, sulphates, etc.

---

### 2. Exploratory Data Analysis (EDA)

* Data distribution analysis
* Feature relationships with wine quality
* Correlation heatmap
* Identification of key influencing variables

---

### 3. Data Preprocessing

* Feature selection
* Train-test split
* Data scaling (if applied)

---

## 🤖 Models Used

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Random Forest Classifier

---

## 📊 Model Evaluation

* Accuracy score
* Confusion Matrix
* Classification Report (Precision, Recall, F1-score)

---

## ⚙️ Model Optimization

* Hyperparameter tuning using GridSearchCV / RandomizedSearchCV
* Comparison of multiple models to select the best performer

---

## 📈 Key Insights

* Alcohol content and sulphates strongly influence wine quality
* Random Forest performs well due to handling non-linear relationships
* Feature interactions significantly impact predictions

---
