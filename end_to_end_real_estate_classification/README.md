# 🏠 Real Estate Price Prediction (End-to-End Machine Learning Project)

![Project!_overview](../Images/real_estate.png)

## 📌 Overview

This project builds a machine learning model to predict real estate prices based on property features. It demonstrates a complete data science workflow from data preprocessing to model evaluation.

---

## 🚀 Project Workflow

### 1. Data Collection

* Real estate dataset with features such as:

  * Location
  * Area (sq ft)
  * Number of bedrooms/bathrooms
  * Amenities and other attributes

---

### 2. Data Cleaning & Preprocessing

* Handling missing values
* Encoding categorical variables
* Feature scaling

---

### 3. Exploratory Data Analysis (EDA)

* Price distribution analysis
* Feature correlation
* Location-based insights
* Outlier detection

---

## 🤖 Models Used

* Linear Regression
* Random Forest Regressor
* Decision Tree Regressor

---

## 📊 Model Evaluation

* R² Score
* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)

---

## ⚙️ Model Optimization

* Hyperparameter tuning using GridSearchCV
* Model comparison for best performance

---

## 📈 Key Insights

* Location and area are primary drivers of price
* Larger properties with more amenities show higher value
* Ensemble models improve prediction accuracy

---

## 🛠️ Tech Stack

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn
